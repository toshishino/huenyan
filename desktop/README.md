# ふえニャン デスクトップ版（開発プレビュー）

Windows向けアプリ化の第一段階です。Electronのウィンドウから既存の設定画面を開き、Node.js中継サーバーを同時起動します。

## 開発環境での起動
Node.jsをインストールしてから、リポジトリのルートで:

```powershell
cd uta-timer-server
npm install
cd ../desktop
npm install
npm start
```

- アプリ終了時に中継サーバーを停止します。
- 現時点では**配布用exeのビルド・署名・自動更新は未対応**です。
- ポート8787が他のアプリで使われている場合は起動できません。
- OBS表示は既存の `uta-timer.html?obs=1&ws=ws://localhost:8787` を使用します。
- Twitch/YouTubeのイベント受信やOBS実機確認は未検証です。
