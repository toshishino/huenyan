# ふえニャン v1.0 テスト引き渡しチェックリスト

## 今回の実装（要テスト）
- Electronからローカル設定サーバーを起動
- 設定画面からタイマー画面・OBS用URLを開く
- タイマー状態をローカルJSONに保存し、OBS側へWebSocket同期
- 0〜9の数字PNG/WebPを読み込み、OBS表示へ同期
- 数字の色・大きさ・太さ・縁取り・影のUI（現状この文字装飾は端末間同期未対応）

## 開発起動
```powershell
cd uta-timer-server
npm install
cd ../desktop
npm install
npm start
```
設定画面で「タイマー操作画面を開く」。OBSブラウザソースには http://127.0.0.1:8787/timer?obs=1 を設定する。
